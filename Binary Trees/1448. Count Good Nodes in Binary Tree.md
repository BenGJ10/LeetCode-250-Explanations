# 1448. Count Good Nodes in Binary Tree

## Problem Statement

Given a binary tree, a node X in the tree is named `good` if in the path from root to X there are no nodes with a value greater than X.


### Example 1:

```
Input: root = [3,1,4,3,null,1,5]
Output: 4
Explanation: Nodes in blue are good.
Root Node (3) is always a good node.
Node 4 -> (3,4) is the maximum value in the path starting from the root to it.
Node 5 -> (3,4,5) is the maximum value in the path
Node 3 -> (3,1,3) is the maximum value in the path
```
---

## Approach

1. We can solve this problem using a depth-first search (DFS) traversal of the binary tree. The idea is to keep track of the maximum value encountered on the path from the root to the current node.

2. We will define a recursive function `dfs(node, maxVal)` that takes the current node and the maximum value seen so far on the path from the root to that node.

3. In the `dfs` function, we will check if the current node's value is greater than or equal to `maxVal`. If it is, we will increment our count of good nodes.

4. We will then update `maxVal` to be the maximum of the current node's value and `maxVal`, and recursively call `dfs` for the left and right children of the current node.

5. Finally, we will return the count of good nodes after traversing the entire tree.

---

## Code Implementation

```java

public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    private int count = 0;
    
    private void dfs(TreeNode root, int maxVal){
        if(root == null) return;
        
        if(root.val >= maxVal) this.count++;
        maxVal = Math.max(maxVal, root.val);
        
        dfs(root.left, maxVal);
        dfs(root.right, maxVal);
    }
    
    public int goodNodes(TreeNode root) {
        dfs(root, root.val);
        return this.count;
    }
}
```

---

## Complexity Analysis

- **Time Complexity**: O(N), where N is the number of nodes in the binary tree. We visit each node exactly once.

- **Space Complexity**: O(H), where H is the height of the binary tree. This space is used by the recursion stack during the depth-first search. In the worst case, the height of the tree can be equal to the number of nodes (in case of a skewed tree), leading to O(N) space complexity. In a balanced tree, the height would be log(N), leading to O(log N) space complexity.
