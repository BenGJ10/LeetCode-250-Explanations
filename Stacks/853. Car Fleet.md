# 853. Car Fleet

## Problem Statement

There are `n` cars at given miles away from the starting mile 0, traveling to reach the mile `target`. You are given two integer arrays `position` and `speed`, both of length `n`, where `position[i]` is the starting mile of the `i-th` car and `speed[i]` is the speed of the `i-th` car in miles per hour.

Return the number of car fleets that will arrive at the destination.

### Example 1:

```
Input: target = 12, position = [10,8,0,5,3], speed = [2,4,1,1,3]
Output: 3
Explanation:
The cars starting at 10 (speed 2) and 8 (speed 4) will arrive at the destination at the same time (12 hours), forming a fleet. The car starting at 0 (speed 1) will arrive at the destination in 12 hours, forming another fleet. The car starting at 5 (speed 1) will arrive at the destination in 7 hours, forming the last fleet. Thus, there are a total of 3 fleets.   
```

### Example 2:

```
Input: target = 10, position = [3], speed = [3]
Output: 1
Explanation:
There is only one car, so it forms a fleet by itself.
```

---

## Approach

1. Create a list of pairs where each pair contains the position and speed of each car.

2. Sort the list of pairs in descending order based on the position of the cars. This allows us to process the cars from the closest to the target to the farthest.

3. Initialize an empty stack to keep track of the time it takes for each car to reach the target.

4. Iterate through the sorted list of pairs:
   - For each car, calculate the time it takes to reach the target using the formula: `time = (target - position) / speed`.
   - If the stack is empty or the calculated time is greater than the time at the top of the stack, push the calculated time onto the stack. This indicates that this car forms a new fleet.
   - If the calculated time is less than or equal to the time at the top of the stack, it means this car will join the fleet represented by the top of the stack, so we do not push it onto the stack.

5. The size of the stack at the end of the iteration will represent the number of car fleets that will arrive at the destination.

---

## Code Implementation

```java
class Pair{
    int first, second;
    Pair(int first, int second){
        this.first = first;
        this.second = second;
    }
}

class Solution {
    public int carFleet(int target, int[] position, int[] speed) {
        List<Pair> fleets = new ArrayList<>();
        for(int i = 0; i < position.length; i++){
            fleets.add(new Pair(position[i], speed[i]));
        }

        Collections.sort(fleets, (a, b) -> Integer.compare(b.first, a.first));

        Stack<Double> st = new Stack<>();
        for(Pair pair: fleets){
            int start = pair.first;
            int spd = pair.second;
            
            double movementsReq = (double)(target - start) / spd;
            System.out.println(movementsReq);
            if(st.isEmpty() || movementsReq > st.peek()){
                st.push(movementsReq);
            }
        }
        return st.size();
    }
}
```

---

## Complexity Analysis

- **Time Complexity**: O(n log n), where n is the number of cars. This is due to the sorting of the cars based on their starting positions.

- **Space Complexity**: O(n), where n is the number of cars. This is due to the space used for the stack to keep track of the fleets.
