# 155. Min Stack

## Problem Statement

Design a `stack` that supports push, pop, top, and retrieving the minimum element in constant time.

Implement the `MinStack` class:

- `MinStack()` initializes the stack object.

- `void push(int val)` pushes the element `val` onto the stack.

- `void pop()` removes the element on the top of the stack.

- `int top()` gets the top element of the stack.

- `int getMin()` retrieves the minimum element in the stack.

### Example 1:

```
Input
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]
Output
[null,null,null,null,-3,null,0,-2]
Explanation
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin(); // return -3
minStack.pop();
minStack.top();    // return 0
minStack.getMin(); // return -2
```
---

## Approach

We have to design a `stack` that supports push, pop, top, and retrieving the minimum element in constant time. To achieve this, we can use `two stacks`.

1. The first stack will be used to store all the elements of the stack.

2. The second stack will be used to store the minimum elements of the stack.

3. When we `push()` an element onto the stack, we will also check if it is smaller than or equal to the current minimum element (the top of the second stack). If it is, we will push it onto the second stack as well.

4. When we `pop()` an element from the stack, we will also check if it is equal to the current minimum element (the top of the second stack). If it is, we will pop it from the second stack as well.

5. The `top()` operation will return the top element of the first stack, and the `getMin()` operation will return the top element of the second stack.

---

## Code Implementation

```java
class MinStack {
    Stack<Integer> minSt, st;
    
    public MinStack() {
        this.minSt = new Stack<>();    
        this.st = new Stack<>();
    }
    
    public void push(int value) {
        st.push(value);
        if(minSt.isEmpty() || minSt.peek() >= value){
            minSt.push(value);
        }
    }
    
    public void pop() {
        if(st.peek().equals(minSt.peek())) minSt.pop();
        st.pop();
    }
    
    public int top() {
        return st.peek();
    }
    
    public int getMin() {
        return minSt.peek();
    }
}
```

---

## Complexity Analysis

- **Time Complexity**: O(1) for all operations (push, pop, top, getMin) since we are using stacks to store the elements and the minimums. (Technically the operations are O(1) on average, but in the worst case, they can be O(n) if we have to pop all elements to find the minimum. However, since we are maintaining a separate stack for minimums, we can retrieve the minimum in constant time.)

- **Space Complexity**: O(n) where n is the number of elements in the stack. We are using two stacks, one for storing all the elements and another for storing the minimum elements.
