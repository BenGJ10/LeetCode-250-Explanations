# 402. Remove K Digits

## Problem Statement

Given a string representing a non-negative integer `num` and an integer `k`, remove `k` digits from the number so that the remaining digits form the smallest possible number.

### Example 1:

```
Input: num = "1432219", k = 3
Output: "1219"
Explanation: Remove the three digits 4, 3, and 2 to form the new number 1219 which is the smallest possible.
```

### Example 2:

```
Input: num = "10200", k = 1
Output: "200"
Explanation: Remove the leading 1 to form the new number 200 which is the smallest possible.
```

---

## Approach

If we observe the problem, we can see that we need to remove digits from the number in such a way that the resulting number is the smallest possible.

1. We can use a stack to keep track of the digits we want to keep.

2. We iterate through each digit in the input string `num`. For each digit, we compare it with the top of the stack. If the current digit is smaller than the top of the stack and we still have digits to remove (i.e., `k > 0`), we pop the top of the stack (remove that digit) and decrement `k`.

3. After processing all digits, if we still have digits to remove (i.e., `k > 0`), we pop the remaining digits from the stack.

4. Finally, we construct the resulting number from the stack. We also need to handle leading zeros and `return "0"` if the resulting number is empty.

5. The final result is obtained by `reversing` the stack and `converting` it to a string.


---

## Code Implementation

```java
class Solution {
    public String removeKdigits(String num, int k) {
        int n = num.length();
        if(n == k) return "0";
        
        Stack<Character> st = new Stack<>();
        for(int i = 0; i < n; i++){
            char curr = num.charAt(i);
            while(!st.empty() && k > 0 && st.peek() > curr){
                st.pop();
                k--;
            }
            st.push(curr);
        }    

        while(k > 0){
            st.pop(); k--;
        }

        if(st.isEmpty()) return "0";
        
        StringBuilder res = new StringBuilder();
        while(!st.isEmpty()){
            res.append(st.peek());
            st.pop();
        }
        res.reverse();

        int idx = 0;
        while(idx < res.length() && res.charAt(idx) == '0'){
            idx++;
        }
        if(idx >= res.length()) return "0";
        return res.toString().substring(idx);
    }
}
```

---

## Complexity Analysis

- **Time Complexity**: O(n), where n is the length of the input string `num`. Each digit is pushed and popped from the stack at most once.

- **Space Complexity**: O(n), where n is the length of the input string `num`. In the worst case, all digits are stored in the stack.
